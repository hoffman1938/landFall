You are a principal game designer with 20+ years of experience designing multiplayer gambling products that reached over 100 million rounds played.

Your task is NOT to invent a new game.

Your task is to redesign the existing LANDFALL game while preserving its core identity.

The current design document is attached below.

=========================================================
PRIMARY GOAL
=========================================================

LANDFALL must become a game capable of competing with Aviator and JetX.

The redesign MUST preserve:

• six harbors
• storm destroys exactly one harbor
• pari-mutuel economy
• players compete against players
• provably fair RNG
• 20-second rounds

Do NOT replace these systems.

Improve everything around them.

=========================================================
MAIN PROBLEMS THAT MUST BE SOLVED
=========================================================

Problem #1
The optimal strategy becomes obvious.

Current optimal play:

wait

↓

observe

↓

jump into emptiest harbor

↓

repeat.

This must disappear.

The game should create multiple viable strategies instead of one mathematically dominant strategy.

---------------------------------------------------------

Problem #2
Bots.

The current game is easily solvable by bots that calculate EV during the final second.

Design anti-bot mechanics that preserve fairness while preventing deterministic automation.

Examples are NOT required to be these:

• imperfect information
• delayed information
• hidden variables
• soft uncertainty
• commitment mechanics
• fake signals
• simultaneous decisions

Find better solutions.

---------------------------------------------------------

Problem #3
Skill gap.

Professional players will continuously extract value from casual players.

The redesign must reduce exploitation while preserving a high skill ceiling.

Skill should exist.

Predatory optimization should not.

---------------------------------------------------------

Problem #4
Emotion.

Current gameplay is intellectually satisfying.

It lacks emotional tension.

Aviator succeeds because tension rises every second.

LANDFALL must generate increasing psychological pressure before impact.

Design mechanics that create anticipation.

---------------------------------------------------------

Problem #5
Visual excitement.

Current gameplay:

Choose.

Wait.

Explosion.

Repeat.

This lacks spectacle.

Create visual systems that make every round memorable WITHOUT affecting fairness.

---------------------------------------------------------

Problem #6
Replayability.

After hundreds of rounds players should still discover:

new situations

new mind games

new strategic decisions

not simply repeat identical EV calculations.

---------------------------------------------------------

Problem #7
Decision depth.

Every round should contain multiple meaningful decisions instead of one click.

Players should constantly ask:

Should I move?

Should I stay?

Should I bluff?

Should I bait others?

Should I split?

Should I risk?

Should I defend?

=========================================================

=========================================================

Every mechanic must satisfy these rules.

1.
Easy to understand in under 15 seconds.

2.
Difficult to master after hundreds of rounds.

3.
Impossible to perfectly solve.

4.
Impossible to dominate using simple automation.

5.
Creates emotional tension.

6.
Creates spectator moments.

7.
Creates social interactions.

8.
Produces viral clips.

9.
Looks exciting on Twitch.

10.
Works equally well on desktop and mobile.

fake complexity

=========================================================
EXTRA REQUIREMENT
=========================================================

Challenge every assumption.

Do NOT assume the current mechanics are optimal.

If a mechanic creates a dominant strategy, redesign it.

If a mechanic can be botted, redesign it.

If a mechanic creates boring waiting time, redesign it.

Think like Riot Games, Valve, Supercell, Pragmatic Play and Spribe combined.

The goal is not to make LANDFALL slightly better.

The goal is to create the next category-defining gambling game.
Before proposing any feature, evaluate it against these five questions.

1. Does this make the game more emotional?

2. Does this create more meaningful player decisions?

3. Does this reduce bot advantage?

4. Does this create memorable moments?

5. Would a player tell a friend about this feature?

If at least four answers are not YES,
discard the feature.
check what has been done and what needs to been done from those tasks. fix if something needs to be fixed.
